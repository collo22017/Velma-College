# CODEA University Website

Welcome to the official website project for **CODEA University**.

This project is a responsive university website designed to provide visitors, students, and prospective applicants with information about the university, its courses, admissions, and contact details.

## About the Project

The CODEA University website was developed using HTML, CSS, and JavaScript. It features a modern black-and-gold design that gives the website a professional university appearance.

The website is designed to make it easy for visitors to explore the university and make enquiries.

## Website Features

The website includes the following sections:

### 1. Home
- University introduction.
- Attractive campus background.
- Welcome message.
- Navigation menu.

### 2. About Us
- Information about CODEA University.
- University introduction and background.

### 3. Courses
- Display of available academic programmes.
- Course information presented in organised cards.

### 4. Admissions
- Information for prospective students.
- Admissions call-to-action section.

### 5. Contact Us
- University contact information.
- Phone contact.
- WhatsApp communication.

### 6. Enquiry Form
- Allows visitors to submit enquiries.
- Connects visitors to WhatsApp with a prepared message.

## Technologies Used

The project was developed using:

- **HTML5** – Website structure and content.
- **CSS3** – Website styling, layout, colours, and responsiveness.
- **JavaScript** – Interactive features and website functionality.
