# 🎓 Student Information Portal

A responsive Student Information Web Application developed using **HTML5, CSS3 and JavaScript**.

## 📌 About the Project

The Student Information Portal is a web-based application designed to provide students with information about Mwangaza College, available academic courses and an online student registration form.

This project was developed as an individual assignment for **Web Technologies and Internet Applications**.

## ✨ Features

- Responsive homepage.
- Institution name and application title.
- Navigation menu.
- About section.
- Display of available courses.
- Student registration form.
- JavaScript form validation.
- Registration success message.
- Mobile-friendly interface.
- Contact information and copyright footer.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and select Open with Live Server.
5. View the application in your web browser.

## 📝 Registration Form

The registration form collects the following information:

- Student's full name.
- Email address.
- Preferred course.

JavaScript checks that all required fields are completed and that the email address is valid before displaying a success message.

## 📱 Responsive Design

The application uses CSS media queries to adjust its layout for:

- Desktop computers.
- Tablets.
- Mobile phones.

## 🌐 Deployment

The application can be hosted online using **Vercel** by connecting the GitHub repository.

## ⚠️ Important Information

This project demonstrates frontend registration functionality only. Student information is not permanently stored in a database.

The institution name and contact details are sample information.
